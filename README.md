# hr-dashboard-powerbi
This project showcases a professional HR Dashboard built using Power BI, aimed at helping organizations monitor and analyze critical human resource metrics. The dashboard transforms raw HR data into insightful visuals that support data-driven decisions in areas like hiring, retention, employee performance, and compensation.
# HR Dashboard using Power BI
This Power BI project features a fully interactive **HR Dashboard** designed to visualize and monitor key Human Resources metrics, helping organizations make data-driven decisions about workforce planning, employee performance, and retention.
## Dashboard Features
- Employee Count by Department, Role, and Gender  
- Attrition Analysis (Monthly/Annual)  
- Employee Demographics (Age Group, Gender, Tenure)  
- Average Salary by Role and Department  
- Headcount Trend over Time  
- Dynamic filters for Department, Gender, Job Role, and Status
## Dataset Fields
The dashboard uses sample HR data with the following fields:
- `Employee ID`
- `Department`
- `Job Role`
- `Monthly Income`
- `Gender`
- `Hire Date`
- `Attrition`
- `Age`
- `Education Level`
- `Tenure (Years at Company)`
- `Performance Rating`
## Tools & Technologies
- **Power BI Desktop**
- **DAX** for calculated columns and KPIs
- **Custom visuals** and slicers
- **Dark/Neutral theme** with contrasting highlight colors
## How to Use
1. Download or clone this repository
2. Open `HR_Dashboard.pbix` in Power BI Desktop
3. Interact with filters and visuals
4. Replace `sample_hr_data.csv` with your own dataset (if needed)
